# JavaFX アプリ開発
### プロジェクト名：FinalProject
## 概要
steam版のVtubeStadioをJavaFX側で操作、管理できるようにする
## 開発環境

## 手順
1. steam版のVtubeStadioのapiを利用する
2. JavaFX側のGUIでVtubeStadioを操作する
3. JavaFX側での操作をVtubeStadioに反映させる
## 機能
#### 対応しているVtuberのモデルの衣装や表情をJavaFX側で操作できる
- モデルの衣装を着脱できる
- モデルの表情をチェンジできる
- モデルの小物(アクセサリーの着脱ができる)
## 検証
VtubeStadioとJavaFXの両方を立ち上げて確認する
